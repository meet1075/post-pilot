# PostPilot front-end

## What to build
Create the PostPilot interface from the supplied brief as a responsive, front-end-only app, using realistic mock data and simulated loading.

## Screens and interactions
- Provide a sign-in/connect screen and a usable workspace with dashboard, create-post flow, scheduled and posted posts, brand kit, account connections, and settings.
- Make the three-step create flow interactive: generate four mock poster layouts, edit poster text, choose captions and platforms, schedule or publish, and confirm the result.
- Seed six realistic Luigi's Pizzeria posts across posted, scheduled, and draft states. Keep mock records and simulated API functions in one library file.
- Use the supplied warm off-white, tomato-red, serif-and-sans visual direction, accessible controls, responsive navigation, and app-specific page metadata.

## Technical approach
Keep the app at `/` in the existing TanStack Start route. Use the installed shadcn-style controls, Lucide icons, semantic CSS tokens, and front-end state only; do not add real API calls or backend services.
